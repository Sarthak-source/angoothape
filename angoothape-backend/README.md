# angoothape-backend

Express + PostgreSQL API for the angoothaPe retailer app.

Full function list (every route and helper): **[root README](../README.md#backend)**.

```bash
cp .env.example .env
npm install
npm run migrate
npm run seed
npm run dev
```

Listens on `:8080`. Postman: `npm run postman` → `docs/Angoothape-API.postman_collection.json`.
